## Принципы

- **Объём**: только задачи с метками **Yandex** или **TP150** из [README.md](README.md) — 215 уникальных. Остальные
  задачи README — резерв на Фазу B.
- **Неделя** = ~10–12 новых задач + 2–3 повтора = **12–15 задач**. Hard считается за 2 слота.
- **Время**: ~5–6 ч в неделю — 3 сессии по ~2 ч (например, пн / ср / сб), по 4–5 задач за сессию. В недели 1–12 — плюс
  4-я сессия на многопоточность (см. «Параллельный трек» ниже).
- **Внутри темы**: Easy → Medium → Hard, внутри уровня — по частоте в Yandex.
- **Протокол**: каждая задача — по [PROTOCOL.md](PROTOCOL.md), с разбором в `Ошибки.txt` темы.
- **Повторы**: Retention 1–3 → пересдать через 3 дня и через 2 недели. Повторы ставятся в слот «повтор» текущей недели и
  **имеют приоритет над новыми задачами** — если неделя перегружена, переносятся новые.
- **Бюджет протокола**: недели 1–6 — Щадящий, 7–14 — Стандартный, 15+ — Боевой. Переход — по критерию из PROTOCOL.md (5
  задач подряд приняты с первой отправки), даты — ориентир.
- 🎤 — живой мок вместо одной из сессий недели.
